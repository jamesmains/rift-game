# Triffall 1.0 - release checklist

The notes this release worked from, sorted into five buckets, with what is done in the code and what only you can do.
"Done" items have a test in `tests/` unless they say otherwise.

## 1. A complete, verified playthrough

| Item | State |
|---|---|
| A bot plays the main quest from the cottage to the Unmade King and checks every story flag | **Done.** `tests/main_quest.txt` (real walking, real dialogue choices, the combat AI fighting; ~1 min). It found and fixed: party AI stuck behind long paths, gunners idle with no ammo, 2x2 bosses unreachable by the AI, fights where nobody could reach anybody looping forever, the Lich joining the first fight of his crypt. |
| A real person plays start to finish | **Needs you.** Two or three people who have never seen the game. Watch, don't help, write down where they stop. The bot cannot tell you what is fun or where people get lost. |
| A real ending | **Done.** Epilogue slides by choices / reputation / approval, the journey in numbers, credits, keep exploring or desktop. `tests/story_choices.txt`. |

## 2. Content density

| Item | State |
|---|---|
| More side quests (3-4 per town) | **Done: 20 side quests** (10 from 0.9, 9 new, plus Vell's Followers), and 5 companion quests. Hollowmere 3, Brasswick 4 (counting the hermit south of town), Ashfall 3, Murkwater 3, Sunscar 3, Frosthold 3, Millbrook 1. `tests/side_quests_1_0.txt` plays all nine new ones. |
| 2-3 main-quest choices that change something visible | **Done: three.** Greywood parley (goblins leave; a goblin peddler appears; Hollowmere reputation; Farmer Tobb remembers), Vell's followers (Sky Wardens healer in Ashfall or prisoners in Brasswick; Ashfall/Brasswick reputation; the Mayor's reaction), the shards (three endings). All feed the epilogue. |
| Difficulty curve, loot and XP over the whole run | **Done as far as a bot can take it** - see BALANCE.md. The big fix: XP was split between party members, which capped a full party around level 7 against a level-11 finale. **Still needs a human pass**, especially the Lich (Dunmarrow) and the Scar. |

## 3. Feel and presentation

| Item | State |
|---|---|
| Bigger text for the Steam Deck | **Done.** Settings > Access > Large text, and the scaling fix (1280x800 used to show the game at 1x with integer scaling). |
| Colour-blind safe colours for cover and hit chances | **Done.** Settings > Access; plus a cover bar on the target and "in half cover" / "FLANKED" text, so colour is never the only cue. |

| A title / logo moment | **Done.** Logo splash after the BIOS lines; first-launch "Triffall Setup" wizard (its pages set large text and the font, and Finish starts the Tutorial). |

## 4. Robustness

| Item | State |
|---|---|
| Versioned saves that upgrade | **Done.** Format 3; `assets/data/migrations.txt` for renames; unknown ids dropped with a note; newer saves refused clearly. |
| Crash log and a backup of the last save | **Done.** `saves/crash.log` + `crash_recovery.sav`, a restore offer on the next start, `.bak` of every save (used automatically if a save is damaged), an autosave on arriving anywhere new. Tested with a real segfault. |
| A real Windows build on a clean machine | **Half done.** The game (and the demo) now cross-compile for Windows with llvm-mingw; `Triffall.exe` imports only system DLLs (KERNEL32, USER32, GDI32, SHELL32, WINMM and the Universal C Runtime that ships with Windows 10+). **Needs you:** run it on a clean Windows 10/11 PC (no compilers installed), check sound, fullscreen, a gamepad, saving into a folder that isn't Program Files. |
| A Steam Deck test | **Needs you.** STEAM.md section 3.6 lists what to check. |
| Performance in the worst scenes | **Done** (`tools/perf_scenes.txt`): every scene tried - storm at night in town, overworld storm, a 16-unit fight in the dark Scar - updates and renders in about 2 ms a frame (60 fps needs 16.7). Re-check on the Deck. |
