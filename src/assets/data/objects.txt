# Object templates: reusable map objects. Edit them in the Editor's Objects tab.
# A placed object with template=<id> gets the template's type and every key it doesn't set itself, so changing a
# template changes every copy on every map. Keys set on the placed object (x, y, an npc's id, a chest's flag...) win.
#   [template]
#   id=town_guard
#   type=npc
#   name=Town guard
#   sprite=105,2
#   dialogue=guard
#
# 1.1.1: [type] entries (id = an object type) hold what EVERY object of that type uses unless the object or its
# template sets the key itself: placed object > its template > its type > the built-in default (an empty value).
#   sprite = its picture (tile col,row)   opensprite / onsprite = its picture once opened / while its lever flag is set
#   color = draw the picture in this one colour (empty = its own colours)   sound = sound played when it is used
#   onuse = script run when it is used, the same actions as a trigger's script= (heal; item:ID:N; flag:NAME; gold:N;
#           message:Title|Text; ... separated by ;)
#   savepoint: sparkle = 1/0 the twinkle above it, sparklecolor, text = what the log says when you step on it
#   sign: title = the message window's title          door: text = what the log says when it opens
