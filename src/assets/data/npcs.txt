# NPCs: the people and animals of the world. Edit them in the Editor's NPCs tab. (1.1.9)
# A map [npc] object is a placement of one of them: npc=<id> plus its spot (x, y), its own id on that map (used by
# hidenpc=/shownpc=/npcmove= and the save) and when it is there (show=, hide=, moveif=/movex=/movey=). Every other key
# the placement doesn't set, or leaves empty, comes from here - so one NPC can stand in several places, and a placement
# can still give itself its own name= or dialogue= (Ilse in her cell, Old Wick at each stop of the Tutorial).
#   name, sprite (col,row), color (draw it in one colour), dialogue, shop (talking opens it when there is no dialogue),
#   craft (forge | workbench | alchemy | any), board (town id: a notice board), travel=1 (opens coach travel), hostile (creatures
#   it turns into when attacked), script (1.1.10: talking runs scripts/<id>.txt instead - the coachman uses script=coachman),
#   wander=1, notes (for you; the game ignores them)
# Companions: companion=<class id> makes the NPC one; the dialogue action join=<npc id> adds them to the party with
#   partysprite (their picture in the party and in fights; default = sprite), level (empty = the hero's level),
#   stats (str:12,dex:10,... instead of the class's), gear (items equipped on joining; others go to the pack),
#   spells (known besides the class's). Their dialogue= holds the [camp] talk (T on the party screen).
