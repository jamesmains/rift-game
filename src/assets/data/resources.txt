# Resource node types: the things the party can harvest (ore veins, herb patches, scrap heaps).
# Edit them in the Editor's Resources tab. A [gather] object on a map names its type with node=<id> and takes every
# key it doesn't set itself from here, so a change here changes every node of that type on every map.
#   item = what one harvest gives        count = how many (lo-hi)        tool = item needed to work it (empty = bare hands)
#   respawn = days until it can be harvested again                       name = what the log calls it ("Iron vein: picked clean")
#   sprite = its own picture (empty = the map tile under it, recoloured)  color = its colour while it can be harvested
#   spentsprite = picture once picked clean (empty = the same picture)    spent = its colour once picked clean
#   kind = the tile kind generated dungeons put under it
#   styles = generated dungeon styles that scatter it: style[:weight[:count]], e.g. mine:2:2-4,cave
#     (weight = lots in the draw, count = overrides count= in that style). The order of this file matters for the draw.
# 1.1.1: veins are rock piles in the colour of what they give (iron orange, gems blue), so they never look like the
# glowing crystal clusters that are only scenery.
