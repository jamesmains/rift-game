# The Training panel. The LAST [hint] whose if= holds is shown, so the lessons are listed in order and each one holds
# while every lesson before it is done: the panel always names the first thing still to do, even if the player does
# things out of order. Hints for a mode (a fight, the shop, the party screen...) come after all of them, so they win
# while that mode is open.
# {action} names the key (or pad button) for that action on the device in use; {move} = how to walk; {click} = " (or click)".
# Extra conditions: mode:explore|combat|shop|menu|journal|levelup|worldmap|craft, equipped:item, fav:item|spell|any,
# map:id, lit. Lessons that can be undone (wearing the token, carrying bandages, a hotbar slot, a lit torch) are turned
# into flags by whole-map triggers (tut_equipped, tut_crafted, tut_fav, tut_lit) on the player's next step; the "b"
# hints below cover the moment in between.
